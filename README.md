# OIBSIP
OIBSIP – Data Analytics Projects

About This Repository

This repository contains projects completed as part of my Oasis Infobyte Internship Program (OIBSIP).

The projects focus on practical data analytics skills, including data cleaning, exploratory data analysis, customer segmentation, and predictive modeling.

The objective is to apply data analytics concepts to real-world datasets and develop practical problem-solving skills.

Projects

1. Retail Sales – Exploratory Data Analysis (EDA)

- Analyzing retail sales data.
- Identifying sales trends and patterns.
- Exploring business performance through data analysis.

2. Customer Segmentation

- Analyzing customer data.
- Identifying different customer groups.
- Understanding customer behavior and purchasing patterns.

3. House Price Prediction

- Analyzing housing-related data.
- Exploring factors affecting house prices.
- Developing a predictive model for house price estimation.

4. Cafe Sales – Data Cleaning

- Cleaning and preprocessing cafe sales data.
- Handling missing and inconsistent values.
- Preparing data for further analysis.

Skills Demonstrated

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Customer Segmentation
- Predictive Modeling
- Data Interpretation
